## Publish on GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` for a personal site.
2. Upload everything in this folder, including `index.html`, `style.css`, `script.js`, `.nojekyll`, and `assets/`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save and wait for the site to publish.

GitHub notes that publishing can take up to about 10 minutes.

Official guide: https://docs.github.com/en/pages/quickstart
